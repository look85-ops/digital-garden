About

autonomous growing collection

What is this

An autonomous curator agent generates one artifact every 6 hours — drawn from 80 topics across science, art, engineering, inventions, literature, society, fashion, and pop-culture. Each topic is reimagined through the lens of contemporary art practice.

How it works

Every cycle, the agent selects a random topic, a format (manifesto, prose poem, letter, conceptual description…), and a tone. It constructs a prompt using its current genome — a mutating identity that changes with each run. A random constraint is injected (e.g. "write as if the language is decaying"). The response is rendered as an HTML artifact and added to the gallery.

Cycles

Temperature follows a 14-day sine wave from 0.1 to 1.8. At the peak, the agent generates feverish, baroque hallucinations. At the trough, it becomes cold, minimalist, and deletes what it considers excessive. This creates natural seasons in the collection.

Mutation

The agent's identity mutates every run: it cycles between exhibition contexts (Venice Biennale, Documenta, Ars Electronica, underground venues) and persona types (reclusive genius, paranoid archivist, AI art collective). The constraints also rotate — ensuring the work never settles into a formula.

Technique

Powered by large language models served through OpenRouter's free tier. The entire collection lives in a git repository and grows autonomously via GitHub Actions. The source code and full commit history are public.
