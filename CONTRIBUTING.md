# Contributing to Digital Garden

Digital Garden is an art project, not a utility. Contributions are welcome as long as they respect the core concept.

## Core principles (non-negotiable)

- **Impermanence** — each artifact lives 4 hours, then disappears. No archives, no galleries, no "best of", no memory.
- **Autonomy** — the agent chooses topics and generates freely. No curated selections, no human-picked favorites.
- **Soil, not storage** — the garden evolves through decaying traces (`souil.json`), not through accumulating artifacts.

## What contributions are welcome

- Bug fixes in curator.py, sources.py, or the GitHub Actions workflow
- New topics (additions to `sources.py` of the existing format)
- Documentation improvements
- Accessibility or presentation improvements to `index.html` / `about.html`

## What will be rejected

- Any form of archiving, saving, or collecting artifacts
- A second branch or page that serves as a gallery
- "Undo" or rollback functionality for artifacts
- Features that break the 4-hour destruction cycle

## Forking is encouraged

If you want a version with archiving, a gallery, persistent memory — please fork. This garden is a single, impermanent practice. Your fork can be anything you like.
